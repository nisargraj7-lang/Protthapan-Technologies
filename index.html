⚙ Email sending setup (do this once)

A web page cannot send email by itself, so it uses the free EmailJS service (emailjs.com). Create an account → add an Email Service (Gmail etc.) → create a Template that uses these variables: {{to_email}}, {{from_name}}, {{reply_to}}, {{subject}}, {{message}} → copy the three values below.
